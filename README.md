# AuditCraft

**AuditCraft** — простой веб‑конструктор правил для [Linux auditd](https://man7.org/linux/man-pages/man8/auditd.8.html). Он помогает быстро выбрать важные области системы, добавить собственные пути и скачать готовый файл правил `.rules`.

Открыть конструктор: **https://andrei-s96s.github.io/AuditCraft/**

> AuditCraft не подключается к серверу и не отправляет данные: все действия происходят прямо в вашем браузере.

## Что можно настроить

- SSH, sudo и события авторизации;
- учётные записи: `passwd`, `shadow`, группы;
- systemd, hostname и настройки ядра;
- задания cron и at;
- сетевую конфигурацию и firewall;
- привилегированные команды;
- настройки и журналы auditd;
- Docker и другие container runtime;
- любые собственные абсолютные пути.

Для каждого своего пути можно выбрать события:

| Событие | Что фиксируется |
| --- | --- |
| `r` | чтение файла или каталога |
| `w` | запись и изменение содержимого |
| `a` | изменение атрибутов, владельца или прав доступа |
| `x` | запуск файла |

## Как использовать

1. Откройте сайт AuditCraft.
2. Отметьте готовые пресеты, соответствующие вашей системе.
3. При необходимости добавьте свои пути в блоке **«Свои пути»**. Используйте только абсолютные пути, начинающиеся с `/`.
4. Проверьте сгенерированные правила справа.
5. Нажмите **«Скачать .rules»**.

Перед установкой удалите правила для программ или каталогов, которых нет на целевой машине. Набор путей отличается между дистрибутивами и конфигурациями.

## Установка правил

Сначала перенесите скачанный `auditcraft.rules` на Linux‑сервер и положите его в каталог правил auditd:

```bash
sudo install -m 640 auditcraft.rules /etc/audit/rules.d/auditcraft.rules
```

Загрузите правила и убедитесь, что они активны:

```bash
sudo augenrules --load
sudo auditctl -l
```

На системах, где правила загружаются напрямую, может потребоваться перезапуск auditd:

```bash
sudo systemctl restart auditd
```

## Проверка событий

Измените тестовый файл или выполните действие, которое должно быть зафиксировано, затем найдите события по ключу правила:

```bash
sudo ausearch -k ssh_config
```

Полезные команды:

```bash
# Статус auditd
sudo systemctl status auditd

# Все загруженные правила
sudo auditctl -l

# События за сегодня в удобном виде
sudo ausearch -ts today -i
```

## Важно

- Сначала применяйте новые правила в тестовой среде.
- Не включайте аудит чтения (`r`) для больших, часто используемых каталогов: это быстро увеличивает объём журналов и нагрузку на систему.
- Следите за свободным местом в `/var/log/audit/`.
- Правила должны соответствовать вашей политике безопасности и требованиям организации.
- AuditCraft создаёт правила наблюдения за путями (`-w`). Для сложных сценариев — системных вызовов, архитектур `b32`/`b64`, фильтров UID/AUID — дополните файл вручную или обратитесь к документации auditd.
