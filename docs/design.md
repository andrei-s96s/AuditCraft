# Интерфейс AuditdNexus

Конструктор — рабочий инструмент для администратора Linux. Визуальная иерархия следует его задаче: выбрать источники, добавить пути, настроить доставку, проверить результат.

## Направление

Светлая рабочая поверхность, графитовая навигация и редактор, зелёные состояния выбора и светлый лаймовый акцент для скачивания. Результат закреплён рядом с настройками на широком экране; на телефоне разделы идут последовательно, а навигация остаётся сверху.

Типографика: Golos Text для русского интерфейса, IBM Plex Mono для путей, кода и технических меток. Основные заголовки имеют высокий контраст. Второстепенные подписи не конкурируют с действиями. Иконки источников используют одну геометрию: сетка 24×24 и линия 1.5 px.

Выбор источника обозначается цветом, рамкой и отметкой. Выбранный быстрый профиль остаётся выделенным, пока набор источников ему соответствует. Предпросмотр показывает настоящий файл, число правил и выбранный способ доставки. Вкладки доступны с клавиатуры: стрелки, Home и End. На мобильном экране основные элементы управления имеют высоту не меньше 44 px.

Палитра и размеры задаются в `styles.css`. Декоративные индикаторы соединения с сервером не используются: приложение генерирует конфигурацию локально.

Референсы определяют принципы композиции; цвета, шрифты, структура и тексты подобраны под AuditdNexus.

## Проверка

`npm test` проверяет генерацию и валидацию. `npm run test:browser` проверяет выбор источников и профилей, состояния, клавиатурную навигацию по файлам, копирование, скачивание, ссылки и семь размеров экрана. Скриншоты с реальными шрифтами дополнительно проверяются визуально; отсутствие горизонтального переполнения проверено на ширинах 320–1920 px.
